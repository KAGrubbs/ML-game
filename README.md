# Intro to Machine Learning Game

Introduce machine learning to young learners using Google's [Teachable Machine](https://teachablemachine.withgoogle.com/)! Train your model on the Teachable Machine Website, then insert it into the code to control a simple sidescroller.

## Instructions
1. Create your model on [Teachable Machine](https://teachablemachine.withgoogle.com/).
2. Record two classes and name them UP and DOWN.
3. Upload your model as a sharable link. Copy the link for later.
4. Visit the live page at <url>
5. Enable camera and microphone permissions if necessary.
6. Paste your model link into the textbox.
7. Control the game using your own machine learning model!

To edit, first fork using the green Fork button at the top right. Then clone the repo to your machine using, `git clone <URL>`.
